# Z-MINECRAFT-LAUNCHER
ZMCLauncher（Minecraft启动器Py）简介

一款面向中文用户、用 Python + PyQt5 打造的轻量 Minecraft 启动器，打包为单文件 exe（≤20MB），开箱即用、深色界面、全程中文交互。

核心功能：

账号体系：支持微软正版账号（Device Code 登录，令牌自动刷新）、离线账号，以及兼容 authlib-injector 的第三方 Yggdrasil 登录（国服/私服皮肤站）。
数据目录向导：首次启动引导选择游戏数据存放路径；之后每次启动自动检测路径是否丢失并重弹，避免配置丢失。
启动进度台：实时显示当前步骤、已用时间与进度条，告别"黑屏干等"。
人话日志：游戏控制台输出中文可读日志，方便排查卡顿与报错。
设置适配：可切换进度台开关，界面已做滚动兼容，窗口缩放不再压扁输入框。
适合想在 Windows 上简单管理正版 / 离线 / 私服账号的玩家。
